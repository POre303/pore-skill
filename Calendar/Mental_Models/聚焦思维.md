# 聚焦思维

## 模型定义
> 做事浮躁、贪多求快，只会一事无成，学会聚焦核心、沉下心来，才能突破瓶颈。

在资源有限、注意力稀缺的情况下，主动摒弃边缘事务，将核心资源集中在最重要的单一方向。

## 模型来源
- **提出者**：萨蒂亚·纳德拉（Satya Nadella），微软CEO
- **经典案例**：重塑微软战略时，摒弃繁杂业务，专注于"移动优先、云优先"的核心方向，最终带领微软走出增长困境
- **原始出处**：Calendar/Daily/2026-05-01

## 应用案例（W18）
**场景**：背诵英语长难句时，既想着快点背完去练素描，又担心记不住被抽查

**旧模式**：一心二用 → 效率低下 → 产生敷衍念头

**聚焦思维应用**：
1. 识别核心任务：当前只有"背会长难句"这一个目标
2. 关掉所有干扰（手机通知等）
3. 专注拆解句子成分，逐部分背诵
4. 慢慢找到规律，效率回升

## 适用场景
- 同时面临多个任务诱惑时
- 学习/工作时频繁走神、效率低下
- 战略选择困难、资源分散

## 行动模板
```
1. 当前最重要的单一目标是什么？（只能写一个）
2. 列出正在分散注意力的干扰项
3. 物理/数字环境清理：关闭通知、移走无关物品
4. 为当前目标设定最小完成单元（如：只背这一句，不想后面的事）
5. 完成后才切换到下一个目标
```
