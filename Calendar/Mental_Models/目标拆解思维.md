# 目标拆解思维

## 模型定义
将"画好曲线"这样的大目标，拆成"调整握笔力度""控制运笔速度""保持线条连贯性"三个小目标，先单独练习握笔，再慢慢控制速度，一点点调整。

## 模型来源
- **原始出处**：Calendar/Daily/2026-04-29（此前已学过，本周在素描中深度应用）

## 应用案例（W18）
**场景**：素描曲线练习，握笔手腕酸痛，曲线要么僵硬要么弯曲不均，练了十几张都没有起色

**旧模式**：反复画完整曲线 → 看不到进步 → 挫败感积累

**目标拆解应用**：
1. 把"画好曲线"拆成三个子目标：
   - 子目标A：调整握笔力度
   - 子目标B：控制运笔速度
   - 子目标C：保持线条连贯性
2. 逐个单独练习：先只练握笔力度，再加入速度控制
3. 后期画出的曲线流畅了很多

## 适用场景
- 技能学习中遇到平台期
- 任务看起来庞大、不知从何下手
- 反复尝试整体突破但收效甚微

## 行动模板
```
1. 写下最终大目标
2. 列出实现该目标需要的3-5个关键子能力/子步骤
3. 评估：哪个子能力最薄弱？优先单独练习
4. 设定每个子目标的最小验证标准（如：连续5次达标）
5. 逐个击破后再整合
```
