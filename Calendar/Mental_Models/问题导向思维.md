# 问题导向思维

## 模型定义
> 逃避问题只会让问题越积越多，直面问题、主动拆解，才能逐个突破，实现成长。

从不回避问题，反而主动直面、系统拆解问题，将模糊的焦虑转化为可执行的具体任务清单。

## 模型来源
- **提出者**：杰米·戴蒙（Jamie Dimon），摩根大通CEO
- **经典案例**：从不回避企业发展中的问题，主动直面、拆解问题，带领企业稳步发展
- **原始出处**：Calendar/Daily/2026-05-02

## 应用案例（W18）
**场景**：学习遇到困难就想逃避（素描透视问题、英语听力短板、单词记忆不牢固），导致进步缓慢

**旧模式**：遇到困难 → 拖延/回避 → 问题积累 → 更焦虑

**问题导向思维应用**：
1. 逐一列出当前学习问题：
   - 素描明暗过渡不自然
   - 英语听力反应慢
   - 单词记忆不牢固
2. 针对每个问题制定具体解决办法
3. 执行验证：素描明暗过渡有了明显进步；英语听力改为逐句精听、反复跟读

## 适用场景
- 遇到困难时产生逃避/拖延冲动
- 感觉"哪里都不对"但说不清具体问题
- 多个问题同时积压、感到 overwhelmed

## 行动模板
```
1. 列出当前所有困扰（不设限，全部写下）
2. 对每个困扰追问：这是真问题还是情绪？
3. 将真问题拆分为：现象 → 原因 → 可能的解决方案（至少2个）
4. 选择成本最低、验证最快的方案先行尝试
5. 记录结果：有效/无效，是否需要调整
```
