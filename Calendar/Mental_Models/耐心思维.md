# 耐心思维

## 模型定义
> 像园丁培育植物一样，循序渐进、顺其自然，哪怕过程缓慢，也会坚持打磨作品。

接受成长的时间属性，不因短期未见成果而急躁或放弃，相信持续投入终将产生复利效应。

## 模型来源
- **提出者**：珍妮特·温特森（Jeanette Winterson），英国作家
- **原始出处**：Calendar/Daily/2026-05-01

## 应用案例（W18）
**场景**：素描球体明暗关系，画出来的球体要么明暗不分，要么过渡生硬，练了很久都没有进展

**旧模式**：反复画同一题材 → 进展缓慢 → 急躁想放弃

**耐心思维应用**：
1. 放下画笔（暂停无效重复）
2. 认真翻看教程，观察明暗过渡的细节
3. 一点点调整笔触力度和渐变层次
4. 慢慢找到了感觉

## 适用场景
- 技能练习进入平台期、看不到明显进步
- 产生"我是不是没天赋"的自我怀疑时
- 对比他人进度、产生焦虑时

## 行动模板
```
1. 承认：当前阶段就是需要重复和积累
2. 暂停：停止无效重复，回到基础教程/范例观察
3. 对比：拿出早期作品和现在的作品，寻找隐性进步
4. 最小行动：不要求今天突破，只要求今天比昨天多掌握一个细节
5. 记录：写下今天学到的1个细节（累积可见的成长轨迹）
```
