# 坚持思维

## 模型定义
> 迷茫不可怕，可怕的是在迷茫中放弃，那些看似不起眼的坚持，终会汇聚成照亮前路的光。

承认成长过程的波动性和非线性，在低谷期依靠行动惯性而非情绪来维持前进，相信时间复利。

## 模型来源
- **提出者/案例**：
  - 余华：年轻时创作屡屡碰壁，稿件被无数次退回，却从未放弃，始终坚持写作，最终成为知名作家
  - 里德·哈斯廷斯（Reed Hastings）：创业过程中多次遭遇失败，却始终坚守目标，敢于创新，最终打造出全球知名的流媒体平台（Netflix）
- **原始出处**：Calendar/Daily/2026-05-03

## 应用案例（W18）
**场景**：素描练习陷入严重迷茫，觉得自己进步很慢，怀疑自己是不是没有学习素描的天赋，萌生放弃念头

**旧模式**：对比理想作品 → 自我否定 → 考虑放弃

**坚持思维应用**：
1. 回忆余华和哈斯廷斯的经历：他们的成功都经历了长期挫折
2. 翻看自己这几天的作品对比：虽然进步缓慢，但每一幅都比上一幅更优秀
3. 结合"复盘迭代思维"：每天总结进步，及时调整方法
4. 决心不再急于求成，脚踏实地、坚持到底

## 适用场景
- 产生"我是不是没天赋"的自我怀疑时
- 努力很久但看不到明显成果时
- 周围人放弃、自己也想随波逐流时

## 行动模板
```
1. 识别：当前是「真实的无法继续」还是「情绪性低谷」？
2. 调用证据：翻看自己的历史作品/记录，寻找隐性进步
3. 降低标准：不要求今天完美，只要求今天完成最小行动（5分钟）
4. 切换视角：如果余华/哈斯廷斯在这个位置，他们会怎么做？
5. 记录：写下今天完成的1个最小行动（维持行动惯性）
```
