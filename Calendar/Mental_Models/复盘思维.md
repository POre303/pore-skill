# 复盘思维

## 模型定义
> 所谓高效学习，从来不是机械重复的无效努力，而是学会在错误中沉淀，在复盘里找到问题、解决问题，这样才能事半功倍。

成功人士之所以能稳步进步，核心就是善于**及时总结、查漏补缺**，不忽视任何一个小错误。

## 模型来源
- **提出者**：[[王莹莹]]老师在课上提到/访谈中分享
- **原始出处**：Calendar/Daily/2026-04-29

## 应用案例（W18）
**场景**：背诵近义词时 "affect" 和 "effect" 反复混淆

**旧模式**：盲目重复背诵 → 越背越着急 → 效率低下

**复盘思维应用**：
1. 停下机械背诵
2. 拿出笔记本，建立结构化表格：
   - 左边：单词拼写
   - 中间：词性和核心含义
   - 右边：典型例句
   - 标注：用不同颜色笔标记易混点
3. 梳理后，混乱记忆变得清晰

## 适用场景
- 知识点反复出错/混淆时
- 学习进入瓶颈、效率低下时
- 考试/练习后错题整理

## 行动模板
```
1. 暂停当前行动
2. 记录错误/混淆的具体表现
3. 归类：是理解问题？记忆问题？还是应用场景问题？
4. 建立结构化对照表（对比、例句、易混点）
5. 验证：闭卷回忆，能否准确区分？
```
